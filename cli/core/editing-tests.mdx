title: "Editing and Deleting Tests"
description: "Request changes to saved cases, review exactly which tests are affected, and approve the changes you want."
---

## Editing a test

Find the saved case and read its current steps. The test ID identifies the same case across runs.

```bash
testsprite test list --project "$PROJECT_ID"
testsprite test get "$TEST_ID"
```

Describe the change to the project's agent. If the expected product behavior has changed, give the new expectation and the acceptance criteria that establish it.

```bash
testsprite plan "Update test $TEST_ID so a declined payment leaves all items in the cart" \
  --project "$PROJECT_ID" --steps
```

Review the changed steps and any other cases in the proposal. `testsprite reject "Keep the existing sign-in step"` asks for a revision. When the plan matches the requirement, save it and inspect the case again.

```bash
testsprite apply
testsprite test get "$TEST_ID"
```

## Deleting tests

Give the agent the IDs of the cases you want removed and explain which behavior was retired. Review the **removed** cases in the proposal. With a mixed proposal, `apply --only <ref>` selects the references to approve. `discard` drops the conversation's unsaved work.

```bash
testsprite plan "Remove test $TEST_ID because we retired the legacy checkout page" \
  --project "$PROJECT_ID" --steps
```

After reviewing the proposed removals, apply and confirm the remaining suite.

```bash
testsprite apply
testsprite test list --project "$PROJECT_ID"
```

If a test caught a product defect, use its result to fix the application and run the same test again. [Reading Results](/cli/core/reading-results) · [Running Tests Again](/cli/core/rerun-and-auto-heal)
