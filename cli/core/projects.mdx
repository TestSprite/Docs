title: "Projects"
description: "Find a frontend or backend project, set up its first environment, and update its settings."
---

A project holds a suite of frontend tests for a web app or backend tests for an API. The CLI and the Portal share the same projects. Each project has its own agent, test cases, and named environments.

## Find a project

```bash
testsprite project list
testsprite project get "$PROJECT_ID"
```

Use an ID from `project list` as `PROJECT_ID`. If your workspace has several pages of projects, pass the returned `nextToken` to `--starting-token` or use `--max-items` to read across pages. To use a project across commands, export `TESTSPRITE_PROJECT_ID`.

## Create a project and its first environment

Create the project first. Copy its `projectId` from the JSON output, then add the URL where your app is running. The first environment becomes the default.

```bash
testsprite project create --type frontend --name "Checkout" --output json
```

```bash
export PROJECT_ID="your-project-id"
testsprite project env create "$PROJECT_ID" --name staging --url https://staging.example.com
testsprite project env get "$PROJECT_ID" staging
```

For an API, choose `--type backend` and give the environment the base URL where the API is publicly deployed. For a frontend app running on your machine, start it and save its address, such as `--url http://localhost:3000`, when creating the environment. A new project starts without tests. Once the target is ready, ask its agent for the first cases. [Creating Tests](/cli/core/creating-tests)

## Update project settings

```bash
testsprite project update "$PROJECT_ID" --name "Storefront checkout"
testsprite project update "$PROJECT_ID" --instruction "Use the test catalog for checkout."
testsprite project update "$PROJECT_ID" --test-id-attributes data-testid,data-qa
```

`--instruction` replaces the project's extra instructions. For frontend projects, list the DOM attributes your app uses for stable element selection in priority order. `--clear-test-id-attributes` restores the default. To change the app URL or its test account, update the environment. [Environments](/cli/core/environments)
