<Tip>
Run `testsprite doctor` first. It checks your CLI version, Node runtime, profile, endpoint, credentials, connectivity, Git ignore configuration and installed verification guidance.
</Tip>

<AccordionGroup>

<Accordion title="command not found: testsprite" icon="terminal">
The binary isn't on your `PATH`. Check `node --version` (20.19+, 22.13+, or 24+; 21.x and 23.x are unsupported), then run `npm install -g @testsprite/testsprite-cli`, or use `npx @testsprite/testsprite-cli --version`.
</Accordion>

<Accordion title="Auth error (exit 3) / AUTH_FORBIDDEN" icon="key">
Run `testsprite auth status` to check the active key, workspace and scopes. If the key is invalid, configure a current one with `testsprite setup --no-agent`. In CI, `TESTSPRITE_API_KEY` overrides a profile's saved key. If the command reports `AUTH_FORBIDDEN`, compare `details.requiredScope` with the key's granted scopes and ask a workspace Admin or Owner to check your access. [Authentication and Scopes](/cli/core/authentication#scopes)
</Accordion>

<Accordion title="An older command or flag exits 5" icon="terminal">
Run `testsprite --version` and `testsprite --help`. In 0.17, use `testsprite run --project "$PROJECT_ID" --wait` to run a project, `testsprite run "$TEST_ID" --wait` for a test, and `testsprite run --testlist "$LIST_ID" --wait` for a list. Request test changes with `plan` and approve them with `apply`. Use `result list` and `result get` to read outcomes. In 0.18, `run --local`, `run --local-host` and `run --target-url` were removed: save the address on an environment and pass `--env`. If your coding agent keeps suggesting old commands, run `testsprite agent status` and refresh its target with `testsprite agent install <target> --force`.
</Accordion>

<Accordion title="An environment URL is rejected (exit 5 or 13)" icon="globe">
Set the URL on `project env create` or `project env update`. Use a public HTTP(S) address, or a frontend loopback HTTP address with an explicit port, such as `http://localhost:3000` (an entry path may follow). An unsupported private address or HTTPS loopback is a validation error. A backend project refuses a local address: its environment must point at a publicly deployed API. Creating an environment over your plan's limit returns `FEATURE_GATED` (exit 13).

To change an existing default named `staging`, use `testsprite project env update "$PROJECT_ID" staging --url https://staging.example.com`. For work on your machine, see [Local Apps](/cli/core/local-apps).
</Accordion>

<Accordion title="ci run rejects --target-url (exit 5 or 6)" icon="globe">
Check for an invalid URL or an unreachable preview. A loopback or private address is refused. If the CLI's reachability probe is wrong for your network, `--skip-preflight` skips it. `run` itself no longer takes `--target-url`: save the address as an environment and select it with `--env`.

For `frontend-auth-target-origin-mismatch` (exit 6), the target and the origin required by the environment's recorded session, OTP or login-once step differ. Use an environment configured for the target origin. List launches always take their target from the list's saved bindings. [Environments](/cli/core/environments)
</Accordion>

<Accordion title="The run timed out (exit 7)" icon="clock">
- **Public run or a borrowed tunnel that is still open.** Read `.runs[].runId` from the partial JSON and follow it with `testsprite run wait "$RUN_ID" --timeout 900`. Later integration results may still be pending.
- **Tunnel opened by this command.** The CLI requests cancellation by default and closes its tunnel. Read the reported outcome. If the execution is still running, `testsprite run cancel "$RUN_ID"` stops it. Start a new local run to reopen a tunnel.
- **Unsupported execution status.** If the error says the server cannot report whole-execution status, a longer timeout cannot supply it. Check that your configured endpoint supports CLI 0.17.

See [Cancelling Runs](/cli/core/cancelling-runs).
</Accordion>

<Accordion title="A result was not found (exit 4), or evidence is incomplete (exit 10)" icon="file-magnifying-glass">
`run wait` and `run cancel` take a run ID. `result get` takes a result ID. Run `testsprite result list --run "$RUN_ID" --status passed,failed,running,blocked,cancelled` and choose a result belonging to that execution. Confirm the active workspace with `testsprite auth status` if it still returns 4.

Download to a dedicated directory with `testsprite result get "$RESULT_ID" --out ".testsprite/results/$RESULT_ID"`. A partial download writes `result.json` and available evidence and exits 10. Retry the same result in the same directory. If a failed file was available from an earlier download of that result, the CLI keeps it and marks the entry `kept: true` in the download's `failed` array.
</Accordion>

<Accordion title="A launch was interrupted before it returned a run ID" icon="rotate">
A project listed in `unconfirmedProjects` may already have launched. Replay the complete original command with the returned `retryIdempotencyKey` as `--idempotency-key`. Use `run wait` for any known run IDs. [Output & Scripting](/cli/reference/output-and-scripting)
</Accordion>

<Accordion title="A tunnel launch rejects the concurrency setting (exit 5)" icon="route">
For a project or named local tests, set `--max-concurrency` between 1 and 15. A saved list through a tunnel accepts 1–10. Both default to 5. Specify the limit on the launch.
</Accordion>

<Accordion title="Tunnel limit reached (exit 11)" icon="route">
Run `testsprite tunnel list`, then `testsprite tunnel stop <client-id>` for an unused binding. You can also attach a run to an existing tunnel with `--tunnel-client`. Revoking all your bindings with `tunnel stop --all --confirm` also affects other terminals and CI jobs using them.
</Accordion>

<Accordion title="Rate limited (exit 11)" icon="gauge-high">
Honor the retry delay. A standing rate limit remains exit 11. A transient throttle that consumes the shared `run wait` deadline returns exit 7. Resume the wait with the existing run ID.
</Accordion>

<Accordion title="Insufficient credits (exit 12)" icon="credit-card">
Not retriable. `testsprite usage` shows which workspace the key draws on and its balance. An Admin or the Owner of that workspace buys extra credits from <kbd>Workspace Settings → Billing → Usage</kbd> in the web portal.
</Accordion>

<Accordion title="Workspace paused (exit 13)" icon="circle-pause">
Every write and run is refused, with `details.reason: "paused"`, while the key's workspace is paused: its paid subscription ended while the workspace still needed a paid plan. `auth status` and `usage` show the notice and a billing link. Topping up doesn't resume it; the Owner renews, picks another plan, or downgrades to Free from <kbd>Settings → Plan</kbd>. See [Plans and Pausing](/web-portal/admin/workspaces#plans-and-pausing).
</Accordion>

<Accordion title="Preview a command without running it" icon="flask">
Append `--dry-run --output json` to preview requests or sample data. When credentials are configured, a launch preview may read saved environment metadata to check for an automatic tunnel. It starts no run.
</Accordion>
