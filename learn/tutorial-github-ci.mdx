## What You'll See

- **Choosing an integration**: the **GitHub App** (ideal for managed platforms like Vercel or Netlify) versus **GitHub Actions** (full control over the pipeline)
- **The build phase**: building and starting the app with Docker Compose inside CI
- **Reaching the app from TestSprite**: using a Cloudflare tunnel so TestSprite's cloud can test an app running in CI
- **Reading the results**: execution videos and pass/fail reports, right in the pull request
