**Agent Actions View** shows one run's UI tests as video tiles. Each tile is the recording TestSprite's testing agent captured while running that test. Open <kbd>Test Runs</kbd>, click a run, and it opens on this tab; <kbd>List View</kbd> shows the same results as a table.

<Frame>
  <img src="../../../images/ui-testing-agent-test-run.png" alt="Test Runs list: click into a run to open it" />
</Frame>

## What You'll See

- Tiles grouped by status (<kbd>Running</kbd>, <kbd>Passed</kbd>, <kbd>Failed</kbd>, <kbd>Blocked</kbd>), each with a count, under a header with the run's pass rate.
- A running tile goes **LIVE** once its recording starts, then moves to its final group.
- Failed and Blocked tiles show a one-line diagnosis. Click any finished tile to play it.
- Search by title or description, and filter by status or priority.

<Frame>
  <img src="../../../images/ui-testing-agent-organize.png" alt="Status groups collapsed, with Blocked expanded showing its tiles" />
</Frame>

The tiles show **this run's** results. If a test was re-run on its own afterwards, the newer result is on that test's page.

## When to Use It

- Triage a run at a glance, filtered to Failed.
- Replay a failing test to see what happened on screen, or share the recording with a teammate.

To go through one test step by step, use [Step-by-Step Replay](/web-portal/core/ui/ui-step-by-step).

## Troubleshooting

- **A failed test has no tile.** Its recording wasn't captured this time; the result is still in <kbd>List View</kbd>. Rerun the test to record it again.
- **A video won't play.** Refresh the page to get a fresh playback link.
- **Does playback use credits?** No. Only re-running a test does.
